# insta-assets
인스타그램 vividvivace 게시용 이미지와 영상. 자동 게시 스크립트가 raw 주소로 올린다.

## 폴더 구조
- `essay/YYMMDD_<스레드ID>/` 에세이 캐러셀 (원문: 스레드 dolceconbrio)
- `art/No.NN/` 그림 읽어주는 남자 캐러셀 (비교 특집 포함)
- `art/No.NN/reel/` 같은 회차 릴스 영상 (화·목·토)
- `archive/blog/YYMMDD_<블로그글ID>/` 블로그 카드뉴스 (2026-11-07 중단, 보관용)

## 규칙
- 날짜는 게시일 KST 기준 YYMMDD.
- 테스트 파일은 올리지 않는다.
- 이미 게시된 이미지는 인스타가 따로 보관하므로 폴더를 옮겨도 게시물에는 영향이 없다.
